# 单粒子调试预设(preset_dipole_single.json)

标准倾斜偶极子 + 单粒子注入:用来调试/验证「单粒子工具」的最小闭环。
图结构(13 节点):

```
[倾斜偶极子] → [输出槽B] ──┬─→ [Boris 积分器].b
                          └─→ [磁力线渲染项].data
[单粒子注入].spec → [发射器].init        (接上 = 确定性单粒子模式)
[粒子物种(质子)].types → [发射器].types  (链首物种 = 单粒子种类)
[发射器] → [Boris] → [编码器]
渲染链: 起始 → 磁力线 → 粒子 → 拖尾 → 初条件预览 → 诊断
```

加载方式:UI「应用图」上传本文件;或启动时
`mf_server --graph graphs\preset_dipole_single.json`。
点阵用 `tiny`(烘焙 ~0.5 s,便于反复调参);要看更大视场把 `lattice`
改成 `coarse`(烘焙 ~12 s)。

## 参数速查(选中「单粒子注入」节点在属性面板调)

| 参数 | 含义 | 建议试值 | 预期现象 |
|---|---|---|---|
| `pos_mode` | `rll`=地心距+纬度+经度 / `xyz`=直接坐标 | rll | — |
| `r` | 地心距(Re) | 4 / 6.6 / 9 | 改变 L 壳:r 越大磁场越弱、回旋半径越大 |
| `lat` `lon` | 纬度/经度(度,GSM) | 0 / 30 / 90 | 从不同纬度注入;90°=极区沿开放线 |
| `vel_mode` | `vpitch`=速率+俯仰角+相位(相对局部B) / `vxyz`=三分量 | vpitch | vxyz 时前端可直接画速度箭头 |
| `pitch` | 俯仰角(度) | **90 / 70 / 30 / 2** | 90=赤道捕获漂移;70=磁镜弹跳;**<3°=损失锥→沿场线沉降** |
| `phase` | 回旋相位(度) | 0 / 90 / 180 | 改变初始回旋相位(回旋太小看不见,见下) |
| `v` | 速率(km/s) | 400 / 1000 / 5000 | 越大回旋半径/弹跳越快(上限 3e5) |

其它节点:`发射器.count`(图内粒子数,=1 即单粒子;改 0 = 用全局粒子数)、
`Boris.substeps`(**时间加速**:每帧子步数,20 ≈ 12× 实时)、
`Boris.dt`、`物种.preset`(质子/电子/α)、
`拖尾.trail_length`(单粒子建议 200,能看到完整轨迹)。

## 物理预期(为什么"看不见回旋")

在 r=6.6 Re、偶极子(ps=0.5)处解析 |B|≈141 nT,400 km/s 质子的
**回旋半径只有 ≈30 km ≈ 0.005 Re**(不到 1 像素),回旋周期 ≈0.5 s;
而**弹跳周期约几百秒、漂移周期以小时计**。所以真实尺度下:
- 拖尾画出来的是**平滑的场线弧**(弹跳/漂移),不是螺旋;
- 想看螺旋,用图内原子节点把 B 缩小:`偶极子 → [mul](w=0.01) → 输出槽B`,
  B×0.01 → 回旋半径 ×100 ≈ 0.46 Re、回旋周期 ≈47 s,配合
  `substeps=20` 约 4 秒转一圈,**肉眼可见的螺旋**。
  (老版本是用内核里写死的 100× 洛伦兹放大实现同样效果的;这里用图组合,物理诚实。)

### 网格分辨率会改变 |B|(粒子感受到的是插值后的表)

粒子只认烘焙表,不认解析公式。偶极场 ∝1/r³ 是**凸函数**,三线性插值在
格点之间**偏高**;格距越大偏差越大。r=6.6 处实测(解析 141.1 nT):

| 点阵 | 该处格距 | 表插值 \|B\| | 倍率 | R_g(400 km/s 质子) |
|---|---|---|---|---|
| `tiny`(本预设,已加密) | ≈1.0 Re | **144.6 nT** | ×1.02 | 0.0045 Re |
| `coarse`(默认图,冻结) | ≈7.6 Re | 171.3 nT | ×1.21 | 0.0038 Re |
| 解析值 | — | 141.1 nT | ×1.00 | 0.0047 Re |

`tiny` 三轴外层格距原本只有 9 Re(每轴 1–2 个节点),会把 r>3 壳层内的
场方向变化抹平:近磁轴的极盖场线与解析解偏差达 3–8 Re、部分线还会提前
折回地球。现已加密到 x 56 / y,z 48 点(格距 ~1 Re):
**偏差 3–8 Re → ≤0.24 Re,|B| 误差 +65% → +2.5%**,烘焙从 ~30 ms 到 ~56 ms。
`coarse` 的粗轴是**legacy 位级一致的对照基准,故意冻结**,不要改。

### 为什么外围有一圈"笔直射线"

不是伪影,是几何:偶极子倾角 `ps=0.5 rad` 把**磁北极放到 (0.479, 0, 0.878)**,
而极盖种子是按 **GSM 的 z 轴**撒的,于是 lon≈0 那几条距离磁极轴只有:

| GSM 种子 | 磁余纬 | 偶极子顶点 L | 表现 |
|---|---|---|---|
| lat 60, lon 0 | 1.4° | ∞ | 笔直径向射线 |
| lat 65/70/75, lon 0 | 3.6 / 8.6 / 13.6° | 247 / 44 / 18 Re | 近乎笔直 |
| lat 80/85, lon 0 | 18.6 / 23.6° | 9.8 / 6.2 Re | 开始闭合 |
| lat 60–85, lon 90/180/270 | 29–59° | 1.4–4.2 Re | 球内短闭合环 |

点偶极子的场方向只依赖方向 r̂(`B ∝ (3(m·r̂)r̂ − m)/r³`),磁轴附近
`B ∥ r̂` → 积分曲线就是直线。真实磁层里这些"开放线"会被磁尾拉弯,
纯偶极子没有尾巴,所以它们笔直地延伸并在**表域边界**处终止
(`LeftDomain`:rlim≈9.8 与 ±12 平面)。

## 观测点

1. **初条件预览(L2,服务器算)**:选中注入节点 → 视口出现黄色标记球、
   **绿色速度箭头**(v̂)与**蓝色磁力线方向箭头**(b̂);俯仰角就是两者夹角。
   拖滑杆 → 本地即时估算先动,~250 ms 后服务器预览(含真实局部 B)细化。
2. **属性面板读数**(选中注入节点,面板底部):`|B|`、`v`、`pitch`、相位、
   `R_g`、回旋周期,以及定性判断(磁镜捕获 / 损失锥方向)与缩放提示。
3. **左下角 HUD**:`t`=仿真时间(s,换图归零;`substeps=20`、`dt=0.01`
   时约 10 s 仿真/真实秒)、`n`=帧内粒子数、`fps`、`N/E`=节点/连线数。
4. **拖尾**:单粒子从生成点沿场线运动,拖尾长度 200 点。
5. **沉降**:把 `pitch` 调到 2° → 粒子沿场线冲向极区,`status=1`(沉降)
   后拖尾冻结。
6. **重生确定性**:点「重生粒子」→ 粒子回到同一注入点、同一速度
   (零随机;与老版本随机撒点不同)。

## 自动化验证

```powershell
# 服务器端到端(注入 → 单粒子帧 → 磁镜捕获 → 重生确定性)
.\.venv\Scripts\python.exe tests\test_ws_injection.py
# 预设本身的可加载性 + 单粒子帧
.\.venv\Scripts\python.exe tests\test_preset_single.py
# C++ 侧:注入确定性 + 俯仰角语义 + 预览与生成逐位一致
server\build\headless.exe
```

日志:`logs\server.jsonl` 中 `plan.applied` 会带
`{"ops":…,"count":1,"injection":true}`——可确认注入已生效。
预览一致性由 `headless.exe` 第 7 节断言保证:预览与发射器
**共用** `injection_position` / `injection_velocity`(emitters.h),
两处数学不会漂移。
