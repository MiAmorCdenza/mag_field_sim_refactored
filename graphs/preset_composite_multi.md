# 复合场 · 多种群(preset_composite_multi.json)

四个场模型经**磁层顶模型**合成,驱动三种群(电子/质子/α)从 r=8 Re 球面向内注入。

```
[kp=2] ─┬─→ [T89].kp        [day=172] ─┬─→ [T89].ps
        ├─→ [tail].kp                   ├─→ [tail].ps
        ├─→ [IMF].kp                    ├─→ [dipole].ps
        └─→ [磁层顶].kp                  └─→ [磁层顶].ps
[T89] ─→ [内场混合].base     [tail(harris)] ─→ [内场混合].tail
[内场混合] ─→ [磁层顶].internal
[dipole]  ─→ [磁层顶].dipole     [IMF(polarity=-1)] ─→ [磁层顶].imf
[磁层顶] ─→ [输出槽B] ─┬→ [Boris].b
                       └→ [磁力线].data
[粒子种群:电子 w2 / 质子 w2 / α w1] ─→ [发射器 mode=1(球面) r=8 count=3000]
[发射器] → [Boris dt=0.01, substeps=5] → [编码器] ─ particles ─┬→ [粒子].data
                                                               └→ [拖尾].data
```
点阵 `tiny`(烘焙 ~5.5 s),粒子计划零告警。

## 四种群权重意味着什么

种群表里权重 = **生成占比**(实测 3000 粒子前 400 个:质子 116 / 电子 128 /
α 56 ≈ 2:2:1)。物理上它们只是"同场不同荷质比"的示踪:电子的洛伦兹力方向
相反、回旋半径小 1836 倍(本预设里表现为几乎贴着场线走),α 则更"重"更直。
想看荷质比差异的可见效果,把电子行的 `v_mult` 调大或给质子的 `q` 改小。

## 参数速查

| 位置 | 参数 | 试值 | 现象 |
|---|---|---|---|
| 粒子种群 | `rows`(行表) | 权重 / enabled / 颜色 | 生成占比、种类开关 |
| 发射器 | `mode` | 1(球面)/ 2(体积)/ 0(盘面) | 撒点方式 |
| 发射器 | `max_range` | 6 / 8 / 12 | 撒点球壳半径(Re) |
| 发射器 | `count` | 1000 / 3000 | 粒子数(帧 21 B/粒子) |
| 发射器 | `angle_random` `v_random` | 10/15 → 30/30 | 方向与速率的随机散布 |
| T89 / tail | `kp` | 0.5 / 2 / 5 | 磁层压缩与磁尾强度 |
| tail | `model` | off / harris / flaring / kan | 磁尾模型(见下) |
| IMF | `polarity` | -1(朝日)/ +1(背日) | 帕克螺旋极性 |
| 磁层顶 | `mp_model` | 0 / 1 / 2 | 磁层顶形状模型 |

## 已知取舍与坑

- **tail 模型全开很贵**:`harris/flaring/kan` 是逐点 Python 计算,`tiny` 上
  整套图约 5 s,**`coarse` 上要几十秒到分钟级**。想看大视场就把 tail 换回
  `off`(T89 本身已含磁尾),或只留 T89 + IMF + 磁层顶。
- 发射器 `mode=1`(全向球面)给出的是**半径 = max_range × dist_ratio** 的
  球壳,速度朝心 → 赤道处近似俯仰角 90°(磁镜捕获)。要"体积填充"用 mode=2。
- 粒子数 3000 时粒子帧约 63 KB/帧;再加拖尾(trail_length=24)功耗主要在前端。
- 想只看某一物种:在种群表里把其它行取消勾选(整表推送,服务器即时重编译)。
