# T89 磁层 · 单粒子(preset_t89_single.json)

T89 **外部场**(kp=2)**+ 倾斜偶极子(内部场)**合成磁层总场,再经
**mul(w=0.01)** 标度 + 单粒子注入:在真实磁层场线拓扑里看**可见的回旋螺旋**,
并用俯仰角锥读初条件。

```
[kp=2] ─→ [T89 外部场] ─┐                                    ┌─→ [Boris].b
[day=172] ─→ kp/ps      ├─→ [加法] ─→ [乘法 w=0.01] ─→ [输出槽B] ┤
[day=172] ─→ [偶极子] ──┘                                    └─→ [磁力线].data
[单粒子注入] ─ spec ─┬─→ [发射器].init      [粒子种群(质子)] ─→ [发射器].types
                     ├─→ [初条件预览].data
                     └─→ [俯仰角锥].data
[发射器 count=1] → [Boris dt=0.01, substeps=50] → [编码器] ─ particles ─┬→ [粒子].data
                                                                       └→ [拖尾].data
```
点阵 `tiny`(烘焙 ~5 s);粒子计划零告警(含 `external_only_field` 检查)。

## 为什么要有 mul(w=0.01)

r=6.6 Re 处 400 km/s 质子的**真实**回旋半径只有 ~30 km(0.005 Re,不到一像素),
回旋周期 ~0.5 s —— 屏幕上只会看到一条平滑弧线。把**合成后的总场**乘 0.01
(r=6.6 处总场 ≈119 nT → 1.19 nT):

| 量 | 真实 | ×0.01 后 |
|---|---|---|
| 回旋半径 R_g | 0.005 Re | **0.55 Re** |
| 回旋周期 | 0.55 s | **55 s** |
| 场线几何 | — | **不变**(只缩放幅值,方向不变) |

`substeps=50` 让每帧推进 0.5 s 仿真时间 → 约 110 帧转一圈(几秒钟就能看到螺旋)。
w 在 0.005 ~ 0.05 之间都能看;想看**真实尺度**就把 w 改回 1(螺旋立即消失,
只剩弹跳/漂移弧线)。

## 参数速查

| 位置 | 参数 | 试值 | 现象 |
|---|---|---|---|
| 乘法 | `w`(输入 · w) | 0.01 / 0.005 / 1.0 | 螺旋半径与周期;=1 即真实物理尺度 |
| T89 | `kp`(输入) | 0.5 / 2 / 5 | 磁层压缩程度与场线拓扑 |
| day_source | `day` | 80 / 172 / 264 | 磁轴倾角 ps |
| 单粒子注入 | `pitch` | 90 / 70 / 2 | 90=赤道捕获、70=磁镜弹跳、2=损失锥沉降 |
| 单粒子注入 | `r` | 4 / 6.6 / 9 | L 壳 |
| Boris | `substeps` | 5 / 50 | 时间加速(50 ≈ 每秒 25 s 仿真) |
| 磁力线 | `color_mode` | class / bmag | 拓扑分类 / 场强色标 |

## 已知取舍

- `tiny` 点阵外层格距 ~1 Re:T89 的细节比 `coarse` 略粗,但烘焙快 2-3 倍。
  要看完整磁尾把点阵换 `coarse`(烘焙 ~12 s)。
- ⚠ **T89 只是外部场**,内部(偶极/IGRF)必须自己加 —— 本预设用
  `偶极子 + 加法` 合成。实测(kp=2,赤道面)r=1.5 Re 处 T89 外部场仅 34 nT,
  而偶极子 9244 nT:**漏掉内部场会让内磁层场强低约 100 倍**。图上传时若某个
  槽位只有外部模型,引擎会报 `external_only_field` 告警。
  (默认图与 `preset_composite_multi` 经磁层顶模型的 `dipole` 输入满足同一条。)
- 标度 w 作用在**合成后的总场**上,是"物理诚实"的可见化手段(改的是场,
  不是内核里的洛伦兹力倍率)。
