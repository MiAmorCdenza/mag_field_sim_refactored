# Van Allen 辐射带(preset_van_allen.json)

倾斜偶极子 + **球面随机发生器**:在 r=4.5 Re 球壳上撒 4000 个电子/质子,
速度朝心 → 赤道附近俯仰角≈90° → **磁镜捕获**,形成包围地球的带状结构。

```
[dipole(ps=0.5)] → [输出槽B] ─┬→ [Boris].b
                              └→ [磁力线].data
[粒子种群:电子 / 质子] ─→ [发射器 mode=1(球面) max_range=4.5 count=4000
                          v=400 ±20%  angle_random=15%]
[发射器] → [Boris dt=0.01, substeps=10] → [编码器] ─ particles ─┬→ [粒子].data
                                                               └→ [拖尾].data(关闭)
```
点阵 `tiny`(烘焙 0.1 s),粒子计划零告警。

## 为什么这样能出"带"

`mode=1` = 全向球面发生器:在半径 `max_range × dist_ratio` 的球面上均匀取点,
初速**指向球心**。赤道附近 B 与速度近似垂直 → 俯仰角 ≈90° → 粒子沿场线
来回弹跳(磁镜),同时绕地球漂移;`angle_random`/`v_random` 给出散布,
于是球壳变成一层**有厚度的辐射带**。这正是实测行为:

- 粒子被约束在 r ≈ 4.5 Re 附近的壳层(不会立刻沉降)
- 赤道面上下对称地来回穿插(弹跳),整体缓慢绕地漂移
- 电子(蓝)因荷质比大,漂移方向与质子(红)相反 —— 这是真实物理(电子东向、
  质子西向漂移),在足够长的观察时间里能看出两组颜色沿相反方向错开

## 参数速查(想微调就改这几处,然后「应用图到服务器」并另存预设)

| 位置 | 参数 | 试值 | 现象 |
|---|---|---|---|
| 发射器 | `max_range` | 3 / 4.5 / 6 | **带的位置**(L 壳) |
| 发射器 | `dist_ratio` | 0.8 / 1.0 | 与 max_range 相乘的撒点半径 |
| 发射器 | `count` | 1000 / 4000 / 8000 | 密度(帧 21 B/粒子) |
| 发射器 | `angle_random` | 5 / 15 / 40 | 带厚度(方向散布,%) |
| 发射器 | `v_random` | 0 / 20 / 40 | 速度散布(影响弹跳高度) |
| 发射器 | `v_base` | 200 / 400 / 1000 | 速率 → 回旋半径与弹跳周期 |
| 粒子种群 | `rows` | 权重 / enabled | 电子:质子比例(默认 1:1) |
| Boris | `substeps` | 5 / 10 / 25 | 时间加速 |
| 拖尾 | `trail_length` | 0 / 10 | 4000 粒子建议关闭;开小值看单体轨迹 |
| 磁力线 | `opacity` | 0.45 → 0.2 | 带很密时压暗场线 |

## 已知取舍

- **不适合看回旋**:电子真实回旋半径 ~1e-5 Re,任何分辨率都看不见;本预设
  展示的是**弹跳 + 漂移**尺度。要看回旋请用 `preset_t89_single`(那里用
  `mul(w=0.01)` 缩放场)。
- `tiny` 点阵在 r=4.5 处格距 ~1 Re:带的位置分辨率够用;要更准换 `coarse`
  (但那里 r=4.5 处格距 2-5 Re,反而更粗 —— 这也是本预设选 `tiny` 的原因)。
- 粒子数 4000 + 拖尾开启会明显掉帧;预设里 `trail_length=0` 关闭拖尾。
- 想要"多壳层"的带:目前一个图上只有一个发射器生效(v1),可以先跑一层,
  或用 `mode=2`(体积随机)近似填充;多发射器支持在路线图上。
