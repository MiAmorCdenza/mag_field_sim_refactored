# Van Allen 辐射带(preset_van_allen.json)

**T89 外部场 + 倾斜偶极子(内部场)合成的磁层总场**(kp=2)+ **体积随机播种**:
在 r≤4.5 Re 球体内撒 6000 个电子/质子/α 粒子,速率基准 **c/3**、
**大小与方向均 100% 随机**;损失锥内的沉降,其余被磁镜捕获,逐渐收到稳定轨道
上形成辐射带。

```
[kp=2] ──→ [T89].kp          [day=172] ──→ [T89].ps
[T89 外部场] ─┐                          └─→ [偶极子].ps
              ├─→ [加法] → [输出槽B] ─┬→ [Boris].b
[偶极子]     ─┘                       └→ [磁力线].data
[粒子种群:电子 / 质子 / α粒子] ─→ [发射器 mode=2(体积随机) 球体 r≤4.5 Re
                                   v_base=100000 km/s(c/3) v_random=100%
                                   angle_random=100%  count=6000]
[发射器] → [Boris dt=0.01, substeps=2, substep_cap=200] → [编码器]
[编码器] ─ particles ─┬→ [粒子].data
                      └→ [拖尾].data(关闭)
```
点阵 `tiny`(烘焙 ~6-12 s),粒子计划零告警。

## ⚠ 必须配内部场:T89 只是**外部场**模型

GEOPACK 的 `t89()` 返回**外部磁层场**(磁层顶电流 / 环电流 / 磁尾),
**不含**内部偶极/IGRF。实测(kp=2,赤道面):

| r (Re) | T89 外部场 | 偶极子 | 相加 | 偶极子占比 |
|---|---|---|---|---|
| 1.5 | 34 nT | 9244 nT | 9210 nT | **100%** |
| 2.0 | 29 | 3900 | 3871 | **100%** |
| 4.5 | 6.4 | 342 | 336 | **102%** |
| 6.6 | 10 | 109 | 119 | 91% |
| 10 | 32 | 31 | 63 | 49% |

即**内磁层(r ≲ 6.6 Re)的场几乎全部来自偶极子**;只接 T89 会让场强低约
100 倍 —— 画布看着正常但物理全错。所以本预设是 `T89 + 偶极子 → 加法 → 输出槽`;
引擎也会在图上传时对"只有外部场"的槽位报 **`external_only_field`** 告警
(默认图/复合场预设经磁层顶模型的 `dipole` 输入满足同一条,不报警)。

## 参数为什么这样选

| 量 | 值 | 理由 |
|---|---|---|
| `v_base` | 100000 km/s ≈ c/3 | 相对论量级动能(辐射带质子真实能量就是 MeV 级);Boris 自身含相对论修正,并在 c 处钳制 |
| `v_random` | 100% | 速率大小随机(正态,σ=100%)→ 能量谱宽 |
| `angle_random` | 100% | 方向随机 → 各向同性投掷角分布;由磁场去筛(损失锥沉降、其余捕获) |
| `mode` | 2(体积随机) | 在球体内**均匀**填充(cbrt 采样保证体积均匀),不是薄壳 |
| `dist_ratio` | 0.01 | 球心≈原点(≈地心),球半径由 `spawn_radius_ratio × max_range` 决定 |
| `spawn_radius_ratio` | 1.0 | 球半径 = 4.5 Re |
| `count` | 6000 | 初始损失 + 越界会淘汰一批,存活基数要够 |
| `substeps` | 2 | **显示时间步** = 2×0.01 s = 0.02 s/帧。c/3 下质子回旋周期 ≈0.19 s → 每圈约 9-10 帧,螺旋可见;调到 10 会变"频闪",调到 1 是更慢的慢动作 |

## 实测(t ≈ 4 s 仿真时间,采样 2000 个粒子)

```
存活 630(31.5%)   沉降 45   出界 1325
r ∈ [0.68, 17.45] Re   三色均在:质子 665 / α 689 / 电子 646
```

- **31.5% 存活不是 bug**:体积随机 + 各向同性方向意味着一半粒子朝"外"发射,
  越界即判定死亡(`max_range=15`,+2 容差);沉降的是损失锥内的那一小部分
  (`sin²α < B_inj/B_surface ≈ 1%`,即 α ≲ 6°)。**存活数会随时间趋于稳定轨道
  上的那一批** —— 这正是辐射带的形成过程。
- 死粒子**不会被绘制**(渲染项跳过 status≠0;拖尾对死粒子冻结),所以不会在
  边界上留一圈"冻结粒子"。想让整批重新播撒,按工具栏「🔄 重置粒子」。
- 三色差异可以这样看:**电子**回旋半径最小(≈2.6e-7 Re)且**漂移方向相反**;
  **α 粒子**荷质比 q/m=0.5(质子的一半)→ 回旋半径是质子的 2 倍、同向漂移更快;
  **质子**居中。观察久一点,三种颜色会沿经度方向逐渐错开。

## 参数速查

| 位置 | 参数 | 试值 | 现象 |
|---|---|---|---|
| T89 | `kp`(输入) | 0.5 / 2 / 5 | 磁层压缩与磁尾强度 → 带的不对称程度 |
| T89 | `ps`(输入) | 0.5 / 23.4 | 磁轴倾角(度) |
| 发射器 | `max_range` × `spawn_radius_ratio` | 3 / 4.5 / 6 | **球体半径** → 带的位置与厚度 |
| 发射器 | `v_base` | 30000 / 100000 / 200000 | 速率(km/s);越大回旋半径越大、弹跳越快 |
| 发射器 | `v_random` | 0 / 100 | 速率谱宽 |
| 发射器 | `angle_random` | 0 / 100 | 方向各向同性程度 |
| 发射器 | `count` | 2000 / 6000 / 12000 | 密度(帧 21 B/粒子) |
| Boris | `substeps` | 1 / 2 / 10 | 显示时间步(慢动作 ↔ 快进) |
| 粒子种群 | `rows` | 权重 / enabled | 三种群比例;单看某一种就取消勾选其它行 |
| 拖尾 | `trail_length` | 0 / 6 | 6000 粒子建议关闭;开小值看单体螺旋 |
| 磁力线 | `opacity` / `color_mode` | 0.45 / bmag | 带很密时压暗场线;换场强色标看压缩/拉伸 |

## 已知取舍

- **电子回旋不可分辨**:电子真实回旋周期 ~1e-4 s,而 dt=0.01 s。当前设置下电子
  的**弹跳/漂移**是对的,但逐圈回旋被欠采样(表现为速度方向抖动)。要正确解析
  电子回旋需 dt ≲ 1e-5(可把 `dt` 调到 1e-5、`substeps` 调大);不想被这一点
  干扰就把电子行取消勾选。
- 想看**可见的回旋螺旋**,用 `preset_t89_single`(那里用 `mul(w=0.01)` 缩放场,
  场线几何不变)。
- `tiny` 点阵在 r=4.5 处格距 ~1 Re;要看**完整磁尾**换 `coarse`(视场 ±45 Re,
  烘焙 ~12 s),但那里 r=4.5 附近格距 2-5 Re,带本身会变粗。
- 一个图上目前只有一个发射器生效(v1);想要多层带可复制预设改半径后各自保存。
